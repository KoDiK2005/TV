# Оптимизация Haier Android TV (DVB2K, Android TV 11)

Цель: меньше рекламы, меньше тормозов, минималистичный главный экран с быстрым доступом к нужному.
Root не нужен, гарантия не теряется, **всё обратимо**: приложения отключаются, а не удаляются,
и одной командой `restore` возвращаются обратно.

Делать по порядку: шаг 1 можно сделать пультом за 10 минут, шаги 2–4 дают основной эффект.

---

## Шаг 1. Настройки пультом (без компьютера)

**Главный экран → убрать рекламу и автозапуск видео**
- Настройки → Настройки устройства → Главный экран:
  - «Включить видео-превью» — **выкл**;
  - «Включить аудио-превью» — **выкл**;
  - «Настроить каналы» — выключите все каналы/ряды, кроме нужных (например, YouTube).
- Зажмите кнопку OK на ненужном ряду главного экрана → удалить/скрыть.

**Реклама и сбор данных**
- Настройки → Настройки устройства → Использование и диагностика — **выкл**.
- Настройки → Аккаунты и вход → ваш аккаунт → «Ограничить рекламу/персонализацию» — **вкл**
  (на некоторых прошивках: Настройки → Google → Реклама).

**Скорость**
- Настройки → Приложения → «Все приложения» → для ненужных (Play Игры, Play Фильмы, YouTube Music и т.п.):
  «Остановить» → «Удалить обновления» → «Отключить».
- Настройки → Приложения → Специальный доступ → «Автозапуск»/«Работа в фоне» (если есть) — запретите всем лишним.
- Настройки → Настройки устройства → Заставка → «Выключить» или «Заставка: Нет»
  (Ambient-режим с фото и погодой постоянно грузит память и сеть).

**Режим разработчика (нужен для шагов 3–4)**
1. Настройки → Настройки устройства → Об устройстве → 7 раз нажмите на «Сборка».
2. Настройки → Настройки устройства → Для разработчиков:
   - «Отладка по USB» / «Отладка по сети» — **вкл**;
   - «Анимация окон», «Анимация переходов», «Длительность анимации» — **0.5x**
     (интерфейс станет заметно отзывчивее).

## Шаг 2. Минималистичный лаунчер (главное против рекламы)

Рекламные ряды «Рекомендуем»/«Спонсорский контент» встроены в стандартный лаунчер Android TV —
выключить их полностью без замены лаунчера нельзя. Решение — поставить лёгкий лаунчер из Play Маркета:

| Лаунчер | Особенности |
|---|---|
| **Projectivy Launcher** (рекомендуется) | Без рекламы, гибкая настройка, умеет сам подменять кнопку Home, плитки входов HDMI/эфирного ТВ |
| **FLauncher** | Открытый исходный код, предельно простой: только ряды ваших приложений |

После установки Projectivy: откройте его → Настройки → «Переопределение лаунчера» (Launcher override) — вкл.
Если кнопка Home всё равно открывает старый экран — выполните `launcher` из шага 3,
он отключит стандартный лаунчер.

На главный экран вынесите только нужное: эфирное ТВ (Live TV), HDMI, YouTube, онлайн-кинотеатры, Настройки.

## Шаг 3. Скрипт оптимизации через компьютер (ADB)

### Подготовка
1. Скачайте Android **platform-tools** с developer.android.com/tools/releases/platform-tools
   (Windows/macOS/Linux), распакуйте.
2. Узнайте IP телевизора: Настройки → Сеть и Интернет → ваша сеть.
3. Компьютер и ТВ должны быть в одной Wi-Fi/локальной сети.

### Windows (PowerShell)
```powershell
# из папки с этим репозиторием; путь к adb.exe можно задать так:
$env:ADB = "C:\platform-tools\adb.exe"

powershell -ExecutionPolicy Bypass -File scripts\tv-optimize.ps1 connect 192.168.1.50
# на ТВ появится запрос «Разрешить отладку?» → «Всегда» → OK, затем повторите connect

powershell -ExecutionPolicy Bypass -File scripts\tv-optimize.ps1 info
powershell -ExecutionPolicy Bypass -File scripts\tv-optimize.ps1 scan
powershell -ExecutionPolicy Bypass -File scripts\tv-optimize.ps1 debloat
powershell -ExecutionPolicy Bypass -File scripts\tv-optimize.ps1 optional
powershell -ExecutionPolicy Bypass -File scripts\tv-optimize.ps1 perf
powershell -ExecutionPolicy Bypass -File scripts\tv-optimize.ps1 dns
powershell -ExecutionPolicy Bypass -File scripts\tv-optimize.ps1 launcher
```

### Linux / macOS
```bash
./scripts/tv-optimize.sh connect 192.168.1.50
./scripts/tv-optimize.sh info
./scripts/tv-optimize.sh scan
./scripts/tv-optimize.sh debloat
./scripts/tv-optimize.sh optional
./scripts/tv-optimize.sh perf
./scripts/tv-optimize.sh dns
./scripts/tv-optimize.sh launcher
```

### Что делают команды
| Команда | Действие |
|---|---|
| `info` | модель, версия Android, свободная память, текущий лаунчер |
| `scan` | статус пакетов из списков, ваши приложения и **системные пакеты Haier/рекламы** для ручной проверки |
| `debloat` | отключает заведомо ненужное из `packages/safe.txt` (Play Игры, Play Фильмы, YouTube Music, печать, заставки, отправку отзывов) |
| `optional` | спрашивает про каждый пакет из `packages/optional.txt`: рекомендации, Ambient-режим, Chromecast, голосовой поиск, Netflix, Prime Video |
| `disable <пакет>` | отключить конкретный пакет, найденный через `scan` |
| `uninstall <пакет>` | удалить пакет для пользователя (`pm uninstall -k --user 0`), если отключение не помогает — см. ниже |
| `perf` | анимации 0.5x и очистка кэша приложений |
| `dns [хост\|off]` | Private DNS AdGuard: блокирует рекламные баннеры и трекеры в большинстве приложений |
| `launcher` | отключает стандартный лаунчер и назначает Projectivy/FLauncher лаунчером по умолчанию (без окна выбора с Haier Evo) |
| `restore` | включает обратно всё отключённое, возвращает удалённые для пользователя пакеты (`install-existing`) и стандартный лаунчер, сбрасывает настройки |

### Безопасность
- `packages/never.txt` — защищённые пакеты (системный интерфейс, Настройки, Play Маркет, сервисы Google,
  пульт, клавиатура, эфирное ТВ MediaTek, системные приложения Haier). Скрипт их не трогает;
  `disable` и `uninstall` для них требуют отдельного подтверждения.
- Всё, что отключено или удалено скриптом, записывается в `state/disabled-<устройство>.txt` — `restore` вернёт и это.
- Пакеты Haier после `scan` отключайте по одному и проверяйте, что эфир, HDMI и пульт работают.
  Если что-то сломалось — `restore` и перезагрузка.

### Отключить или удалить для пользователя
`disable` подходит почти всегда. Но есть два случая, когда отключение не работает:

- **Persistent-приложения.** Прошивка помечает некоторые системные приложения флагом `PERSISTENT`,
  и Android запускает их при загрузке **даже отключёнными** — они продолжают занимать память.
  Проверить флаг: `adb shell dumpsys package <пакет> | grep flags=`.
- **Пакеты, которые прошивка включает обратно** при каждой загрузке.

Для них есть `uninstall`: пакет удаляется только для пользователя, файл остаётся в прошивке, данные сохраняются
(флаг `-k`). Такой пакет не запускается совсем, даже persistent. Процесс, который уже работает,
остановится после перезагрузки. Вернуть: `restore` или вручную
`adb shell cmd package install-existing <пакет>`.

### Пакеты Haier: что проверено на DVB2K
Проверено на Haier Android TV DVB2K (Android 11, MediaTek mt5867). После каждого пакета проверялись
эфир, входы HDMI, кнопка Home и падения приложений, затем перезагрузка.

| Пакет | Что это | Как убрать | Результат |
|---|---|---|---|
| `ru.haier.evo` | Haier Evo: экосистема и витрина Haier, аналитика AppMetrica/Firebase, ~34 МБ. Регистрируется как лаунчер и содержит службу перехвата кнопки Home | `uninstall` | После `disable` прошивка включает его обратно при каждой загрузке. После `uninstall` не возвращается |
| `tv.anoki.acr.controller` | ACR-трекер Anoki: распознавание того, что на экране (в т.ч. по HDMI), для рекламы. Собирает рекламный ID, раз в ~18 минут обращается к своему серверу, видит запущенные приложения, ~33 МБ. Окно согласия отключено в прошивке | `uninstall` | Persistent. На проверенном ТВ распознавание было неактивно (`ACR_STATE_UNSUPPORTED`), но может включиться с сервера без согласия |
| `com.haier.yudee.tv` | Трансляция экрана с телефона от Haier, ~30 МБ | `uninstall` | Persistent: после `disable` продолжает запускаться. Chromecast (`com.google.android.apps.mediashell`) остаётся |
| `com.mediatek.android.leanbacklauncher.partnercustomizer` | «Партнёрские» ряды в стандартном лаунчере, ~30 МБ | `uninstall` | Persistent. Не нужен при Projectivy/FLauncher |
| `com.haier.sharetv.webview` | Компонент трансляции экрана Haier | `disable` | Без проблем |
| `com.haier.tvhousekeeper` | «Помощник ТВ», очистка памяти Haier | `disable` | Без проблем |
| `android.autoinstalls.config.haier.hanyang` | Список приложений, которые ТВ сам ставит через Play Маркет | `disable` | Без проблем |
| `com.haier.launcher.haiermatrix` | — | не трогать | Уже отключён мастером первоначальной настройки ТВ |

Не трогали, это рискованно: `com.haierubic.usmartdevice` (может быть связан с пультом или голосом),
`com.haier.tv.hmagicboard` (возможно, быстрое меню по кнопке пульта). Не проверяли:
`com.haier.apps`, `com.haier.apps.evoSmart` (магазин приложений Haier), `com.cvte.haier.tv.appmanager`.

Рекламный ID, который собирает ACR, используют и другие приложения. Отключите персонализацию пультом:
Настройки → Google → Реклама → «Отключить персонализацию рекламы» и «Сбросить рекламный идентификатор».

## Шаг 4. Реклама в YouTube и приложениях

- **Private DNS** (команда `dns`) режет рекламу в большинстве приложений и игр, но **не в YouTube**:
  там реклама идёт с тех же серверов, что и видео.
- Для YouTube без рекламы — **SmartTube** (бесплатный клиент с открытым исходным кодом,
  ставится через APK с официальной страницы проекта на GitHub, есть встроенный SponsorBlock).
- Если в сети есть роутер с поддержкой AdGuard Home/Pi-hole — можно блокировать рекламу сразу на всех устройствах.

## Если что-то пошло не так

```bash
./scripts/tv-optimize.sh restore        # или tv-optimize.ps1 restore
adb reboot
```
Крайний случай — сброс к заводским настройкам (Настройки → Настройки устройства → Сброс):
отключённые приложения вернутся, но и все настройки/аккаунты придётся вводить заново.

## Чего ждать
- Меньше фоновых процессов → больше свободной памяти, быстрее переключение приложений.
- Главный экран без рекламы и автозапуска трейлеров.
- Важно: процессор и объём памяти ТВ не изменить. Если после всех шагов приложения всё равно
  тормозят — внешняя приставка (Chromecast с Google TV, Xiaomi Mi Box и т.п.) ощутимо быстрее
  встроенной платформы большинства бюджетных ТВ.
